# 双面 Tom and Jerry 彩色剪纸模板

这个目录提供一张 A4 可打印的双面彩色剪纸模板：

- `tom-jerry-double-sided-template.html`
- `tom-jerry-double-sided-template.svg`

推荐下载并打开 `tom-jerry-double-sided-template.html`。这是单文件版，图案已经嵌入 HTML，单独下载、移动或改名后仍然可以显示和打印。

`tom-jerry-double-sided-template.svg` 是备用矢量源文件，适合用浏览器、Inkscape、Illustrator 等软件打开。

说明：Tom and Jerry 不是迪士尼出品，而是 MGM / 华纳体系的经典动画角色。模板采用灰蓝色猫和棕色小老鼠追逐造型：Tom 在后面伸手追，Jerry 在前面回头跑，适合打印后做成双面剪纸吊饰或摆件。

这版按“能剪出来”的目标设计：角色表情和颜色主要靠彩色打印保留，真正必须剪的只有米黄色底板最外侧粗黑线。

## 使用方法

1. 用 A4 纸按 100% 比例打印 HTML 或 SVG，不要选择“适合页面”缩放。
2. 新手建议跳过红色虚线，不刻内部细节；高手可以先沿红色虚线处理少量可选镂空。
3. 沿蓝色中线轻轻压痕，然后让印刷面朝外对折。
4. 在中线附近和空白背面薄薄涂胶，把两个圆形定位标记对齐后压平。
5. 胶干后，只沿米黄色底板最外侧粗黑色轮廓剪下。耳朵、尾巴、手脚附近慢剪。
6. 剪完后可以用黑色细笔补描胡须和表情线，让追逐动作更生动。

## 这版的造型重点

- Tom 的鼻子改为居中对称的黑鼻头，连接嘴线和笑脸。
- Tom 有黄色眼睛、白色嘴巴和肚皮、粉色耳朵、伸手追赶的动作。
- Jerry 有圆耳朵、棕色身体、米色脸和肚皮，姿态是边跑边回头。
- 蓝色动作线表现追逐方向，米黄色底板是一整块连续外轮廓，保证剪完后结构更结实。

## 线条说明

- 米黄色底板最外侧粗黑色实线：最终外轮廓剪切线，也是新手唯一必须剪的线。
- 红色虚线：可选镂空线，适合用刻刀先开孔。
- 蓝色虚线：对折线。
- 灰色区域：涂胶定位区。

## 手工建议

- 新手可以先用 120g 到 180g 的卡纸；普通打印纸也可以，但尾巴和耳朵会比较软。
- 如果要做吊饰，可以在灰猫头顶附近的小圆孔穿线。
- 需要更强的剪纸感时，可以把红色虚线区域剪掉；如果给儿童制作，建议只剪外轮廓。
