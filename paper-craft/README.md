# 双面 Tom & Jerry 剪纸模板

这个目录提供一张 A4 可打印的双面剪纸模板：

- `tom-jerry-double-sided-template.svg`

## 使用方法

1. 用 A4 纸按 100% 比例打印 SVG，不要选择“适合页面”缩放。
2. 先沿红色虚线处理可选镂空细节，例如眼睛、嘴巴、耳朵和动作线。想让成品更结实的话，可以少剪几个细节，只保留外轮廓。
3. 沿蓝色中线轻轻压痕，然后让印刷面朝外对折。
4. 在中线附近和空白背面薄薄涂胶，把两个圆形定位标记对齐后压平。
5. 胶干后，沿黑色外轮廓剪下。耳尖、尾巴、老鼠耳朵这些小转角建议慢剪。
6. 剪完后可以用黑色细笔补描胡须和表情线，让汤姆和杰瑞的追逐动作更生动。

## 线条说明

- 黑色实线：最终外轮廓剪切线。
- 红色虚线：可选镂空线，适合用刻刀先开孔。
- 蓝色虚线：对折线。
- 灰色区域：涂胶定位区。

## 手工建议

- 新手可以先用 120g 到 180g 的卡纸；普通打印纸也可以，但尾巴和耳朵会比较软。
- 如果要做吊饰，可以在汤姆头顶附近的小圆孔穿线。
- 需要更强的剪纸感时，可以把红色虚线区域剪掉；如果给儿童制作，建议只剪外轮廓并用画笔补细节。
